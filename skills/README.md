# AI Investment Team Skills

Claude skills the team uses. Each folder holds one skill as a `SKILL.md` file.

## Install

Download the skill folder and copy it into `~/.claude/skills/` (Claude Code), or upload the `SKILL.md` in Claude.ai under Settings > Capabilities > Skills.

## Skills

- [ainu-test-skill-1](ainu-test-skill-1/SKILL.md): turns a GPU-rental company brief into a sourced Google Sheets cash-flow workbook.
